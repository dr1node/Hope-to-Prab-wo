# Ruang Diskusi Pemerintahan Indonesia 🇮🇩

Tempat berdiskusi, bertukar gagasan, dan menganalisis kebijakan serta tata kelola pemerintahan Indonesia secara terbuka, kritis, dan bertanggung jawab.

## Tujuan

- Membahas kebijakan publik dan dampaknya bagi masyarakat.
- Mendorong diskusi berdasarkan data dan sumber tepercaya.
- Memahami peran lembaga negara dan sistem pemerintahan.
- Mengembangkan gagasan untuk perbaikan pelayanan publik.
- Mendorong partisipasi masyarakat dalam demokrasi.

## Prinsip Diskusi

1. Kritik kebijakan, bukan menyerang pribadi.
2. Sertakan sumber untuk klaim faktual.
3. Hormati perbedaan pandangan.
4. Jangan menyebarkan informasi yang belum terverifikasi.
5. Hindari ujaran kebencian, ancaman, dan doxing.

## Topik

- Kebijakan ekonomi
- Pendidikan
- Kesehatan
- Hukum dan keadilan
- Korupsi dan transparansi
- Lingkungan
- Infrastruktur
- Demokrasi dan pemilu
- Pelayanan publik

## Cara Berpartisipasi

Buka tab **Discussions** untuk membuat topik diskusi.

Jika Discussions belum tersedia, gunakan tab **Issues** sebagai tempat mengusulkan topik.

Baca [Panduan Diskusi](docs/panduan-diskusi.md) sebelum berpartisipasi.
